  <name>Task 1: Create backfill service with Langfuse tracing</name>
  <files>backend/app/services/backfill_service.py</files>
  <action>
Create `backend/app/services/backfill_service.py` with:

1. An async function `backfill_document_content()` that:
   - Connects to SQLite using DB_PATH
   - Queries all documents with status='completed' that do NOT have a row in document_content (LEFT JOIN ... WHERE dc.document_id IS NULL)
   - For each document:
     - If `needs_conversion(filename)`: get file path via `get_upload_path()`, check if file exists on disk, run `convert_document()` via `asyncio.to_thread()` (NOT directly -- Docling is CPU-intensive per RESEARCH.md Pitfall 5)
     - If plaintext: use `read_file_text()`
     - Compute line_count (text.count("\n") + 1) and char_count (len(text))
     - INSERT INTO document_content using ON CONFLICT DO UPDATE (upsert, same as ingestion pipeline)
     - Wrap each document in try/except -- log failures, don't crash the whole backfill
   - Return a stats dict: {"success": N, "failed": N, "skipped": N, "total": N}
   - Process documents sequentially (not concurrently) to avoid memory issues with Docling

2. Add `@observe(name="backfill_document_content")` decorator from `langfuse.decorators` per CLAUDE.md observability rules.

3. Use `langfuse_context.update_current_observation(metadata=stats)` at the end to attach the stats to the Langfuse trace.

4. Add standard logging: `logger = logging.getLogger(__name__)`, log each document processed and final summary.

5. For documents whose source files are missing on disk:
   - Attempt to reconstruct from ChromaDB chunks as fallback (query chunks by document_id from the chroma collection, concatenate by chunk_index order)
   - If chunks also unavailable, increment "failed" counter and log warning
   - This handles RESEARCH.md Pitfall 3

1. In `backend/app/routers/documents.py`, add a new endpoint:

   ```python
   @router.post("/admin/backfill-content")
   async def backfill_content(
       current_user: dict = Depends(get_current_user),
       db: aiosqlite.Connection = Depends(get_db),
   ):
       """Backfill document_content for existing documents missing full markdown."""
       from app.services.backfill_service import backfill_document_content
       stats = await backfill_document_content()
       return stats
   ```

   NOTE: This endpoint is user-authenticated (any logged-in user can trigger it). In a multi-user system you might restrict to admin, but this project has no admin role concept. The backfill service already processes all users' documents, which is fine for this single-user-focused tool.

   Place this endpoint BEFORE the `/{document_id}` catch-all routes to avoid path conflicts.

2. Extend `tests/e2e/api/data-foundation.spec.ts` (created in Plan 01) with additional tests:
