1. Create `backend/migrations/005_folders_and_content.sql` with the following DDL (all using IF NOT EXISTS for idempotency):

   a. **Folders table** (adjacency list + materialized path):
      - id TEXT PRIMARY KEY
      - user_id TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE
      - name TEXT NOT NULL
      - parent_id TEXT REFERENCES folders(id) ON DELETE CASCADE
      - path TEXT NOT NULL (materialized path e.g. "/reports/2024")
      - created_at TEXT NOT NULL DEFAULT (datetime('now'))
      - updated_at TEXT NOT NULL DEFAULT (datetime('now'))
      - UNIQUE(user_id, parent_id, name)
      - Indexes: idx_folders_user_id, idx_folders_parent_id, idx_folders_path(user_id, path)

   b. **document_content table**:
      - document_id TEXT PRIMARY KEY REFERENCES documents(id) ON DELETE CASCADE
      - user_id TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE
      - content TEXT NOT NULL
      - line_count INTEGER NOT NULL DEFAULT 0
      - char_count INTEGER NOT NULL DEFAULT 0
      - created_at TEXT NOT NULL DEFAULT (datetime('now'))
      - Index: idx_document_content_user_id

   c. **FTS5 virtual table**:
      - CREATE VIRTUAL TABLE IF NOT EXISTS document_content_fts USING fts5(content, content='document_content', content_rowid='rowid', tokenize='unicode61')

   d. **FTS5 sync triggers** (all three -- insert, update, delete):
      - dc_fts_insert: AFTER INSERT ON document_content -> INSERT INTO document_content_fts(rowid, content)
      - dc_fts_delete: AFTER DELETE ON document_content -> INSERT INTO document_content_fts(document_content_fts, rowid, content) VALUES('delete', ...)
      - dc_fts_update: AFTER UPDATE ON document_content -> delete old + insert new

   Use exact SQL from RESEARCH.md Pattern 1, Pattern 2, and Code Examples section.

   ```python
   # Store full extracted markdown for grep/read tools
   line_count = text.count("\n") + 1
   char_count = len(text)
   await db.execute(
       """INSERT INTO document_content (document_id, user_id, content, line_count, char_count)
          VALUES (?, ?, ?, ?, ?)
          ON CONFLICT(document_id) DO UPDATE SET
              content = excluded.content,
              line_count = excluded.line_count,
              char_count = excluded.char_count""",
       (doc_id, user_id, text, line_count, char_count),
   )
   await db.commit()
   ```

   Use ON CONFLICT...DO UPDATE (upsert) syntax, NOT INSERT OR REPLACE. This is critical per RESEARCH.md Pitfall 4 -- INSERT OR REPLACE breaks FTS5 rowid mapping because it fires DELETE+INSERT triggers instead of UPDATE trigger.
