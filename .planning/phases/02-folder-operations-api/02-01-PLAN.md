2. Create `backend/app/services/folder_service.py` with these functions (all async, all take `db: aiosqlite.Connection` and `user_id: str`):

   a. **`validate_folder_name(name: str) -> str`** -- Strip whitespace, reject empty, reject names containing `/\<>:"|?*` or control chars, reject `.` and `..`. Raise HTTPException(400) on invalid. Return stripped name.

   b. **`compute_folder_path(db, parent_id, folder_name, user_id) -> str`** -- If parent_id is None, return `/{folder_name}`. Otherwise, query parent's path from folders table (WHERE id=parent_id AND user_id=user_id), raise ValueError if not found, return `{parent_path}/{folder_name}`.

   c. **`check_name_conflict(db, user_id, parent_id, name, exclude_id=None)`** -- Check for duplicate folder names in the same parent. Handle NULL parent_id separately (use `parent_id IS NULL` in query). Raise HTTPException(409, "A folder with this name already exists in the target location") if conflict found.

   d. **`create_folder(db, user_id, name, parent_id=None) -> dict`** -- Validate name, check name conflict, validate parent exists and belongs to user (if parent_id provided, raise 404 if not found), compute path, INSERT with uuid4 id, return folder dict. Add `@observe(name="create_folder")` decorator.

   e. **`rename_folder(db, user_id, folder_id, new_name) -> dict`** -- Validate name, fetch folder (404 if not found or wrong user), check name conflict (exclude current folder), compute old_path, compute new_path (using folder's parent_id + new_name), UPDATE folder name and path, update all descendant paths using `UPDATE folders SET path = ? || substr(path, ? + 1), updated_at = datetime('now') WHERE user_id = ? AND path LIKE ? || '/%'` with params (new_path, len(old_path), user_id, old_path). Return updated folder. Add `@observe(name="rename_folder")`.

   f. **`would_create_cycle(db, folder_id, target_parent_id, user_id) -> bool`** -- If target_parent_id is None, return False. If target_parent_id == folder_id, return True. Use recursive CTE to walk ancestors from target_parent_id upward, check if folder_id appears. Return True if cycle detected. Use exact SQL from RESEARCH.md Pattern 4.

   g. **`move_folder(db, user_id, folder_id, new_parent_id) -> dict`** -- Fetch folder (404 if not found), check cycle detection (400 "Cannot move a folder into its own subtree"), validate new parent exists and belongs to user (if not None, 404 if not found), check name conflict in new parent, compute new path, UPDATE parent_id and path, update descendant paths (same pattern as rename). Return updated folder. Add `@observe(name="move_folder")`.

   h. **`delete_folder(db, user_id, folder_id, chroma_collection)`** -- Fetch folder (404 if not found), use recursive CTE to find ALL documents in folder and subfolders (see RESEARCH.md Pattern 5), delete ChromaDB chunks for each document (try/except, continue on error), delete disk files via `delete_file(user_id, doc_id)`, delete the documents from SQLite, THEN delete the folder (CASCADE handles subfolders). Commit. Add `@observe(name="delete_folder")`.

   i. **`list_folders(db, user_id) -> list[dict]`** -- SELECT all folders WHERE user_id, ORDER BY path. Return list of dicts.

   j. **`get_folder(db, user_id, folder_id) -> dict | None`** -- SELECT single folder WHERE id AND user_id. Return dict or None.

   k. **`get_folder_tree(db, user_id, root_id=None) -> list[dict]`** -- SELECT all folders for user (optionally filtered to descendants of root_id using path LIKE prefix), build tree using iterative parent_id grouping (see RESEARCH.md Code Examples "Building a Folder Tree from Flat List"). Include document_count via LEFT JOIN on documents(folder_id). Return tree structure.

   l. **`get_folder_documents(db, user_id, folder_id) -> list[dict]`** -- Verify folder exists and belongs to user (404 if not), SELECT documents WHERE folder_id AND user_id, return list of document dicts.

   Add `import logging` and `logger = logging.getLogger(__name__)` at module level. Import `@observe` from `langfuse.decorators`. Import `uuid`, `HTTPException` from fastapi. Import `delete_file` from `app.services.storage_service`.

   For dict returns, use `dict(zip([col names], row))` pattern or `db.row_factory = aiosqlite.Row` then `dict(row)`.

   - `POST /folders` (201) -- CreateFolderRequest body, calls create_folder service, returns FolderResponse

   All endpoints use `Depends(get_current_user)` and `Depends(get_db)`. Follow existing router pattern from documents.py.

   IMPORTANT: Place the `/folders/tree` route BEFORE `/folders/{folder_id}` to avoid FastAPI matching "tree" as a folder_id.

   ```typescript
   // --- Folders ---

   async createFolder(name: string, parentId?: string) {
     return this.request.post(`${BACKEND_URL}/folders`, {
       headers: { ...this.headers(), "Content-Type": "application/json" },
       data: { name, parent_id: parentId ?? null },
     });
   }

   async listFolders() {
     return this.request.get(`${BACKEND_URL}/folders`, {
       headers: this.headers(),
     });
   }

   async getFolderTree(rootId?: string) {
     const url = rootId
       ? `${BACKEND_URL}/folders/tree?root_id=${rootId}`
       : `${BACKEND_URL}/folders/tree`;
     return this.request.get(url, {
       headers: this.headers(),
     });
   }

   async getFolder(id: string) {
     return this.request.get(`${BACKEND_URL}/folders/${id}`, {
       headers: this.headers(),
     });
   }

   async renameFolder(id: string, name: string) {
     return this.request.patch(`${BACKEND_URL}/folders/${id}`, {
       headers: { ...this.headers(), "Content-Type": "application/json" },
       data: { name },
     });
   }

   async moveFolder(id: string, parentId: string | null) {
     return this.request.patch(`${BACKEND_URL}/folders/${id}/move`, {
       headers: { ...this.headers(), "Content-Type": "application/json" },
       data: { parent_id: parentId },
     });
   }

   async deleteFolder(id: string) {
     return this.request.delete(`${BACKEND_URL}/folders/${id}`, {
       headers: this.headers(),
     });
   }

   async getFolderDocuments(id: string) {
     return this.request.get(`${BACKEND_URL}/folders/${id}/documents`, {
       headers: this.headers(),
     });
   }
   ```
