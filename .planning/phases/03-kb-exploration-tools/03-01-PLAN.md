```sql
    line_count INTEGER NOT NULL DEFAULT 0,
    char_count INTEGER NOT NULL DEFAULT 0,
    created_at TEXT NOT NULL DEFAULT (datetime('now'))
);
```

  <action>
    Create `backend/app/services/kb_tools_service.py` implementing:

    1. **Path helpers** (internal, no @observe):
       - `_validate_path(path: str) -> str | None`: Returns normalized path or None if invalid (contains "..", doesn't start with "/"). Root "/" returns "/".
       - `resolve_folder_id(db, user_id, path) -> str | None`: Resolves virtual path to folder ID. Returns None for root ("/") or not found.
       - `resolve_document(db, user_id, path) -> tuple[str, str] | None`: Resolves full path to (document_id, filename). Last segment is filename, rest is folder path. For root-level docs, just the filename.

    2. **kb_ls(db, user_id, path="/") -> LsResult**: Query subfolders (parent_id match) and files (folder_id match). Handle root as parent_id IS NULL / folder_id IS NULL. Sort by name. If path != "/" and folder not found, return error.

    3. **kb_tree(db, user_id, path="/", depth=3, limit=50) -> TreeResult**: Use recursive CTE (from RESEARCH.md Pattern 2) to get folder hierarchy up to depth. Join documents at each folder level. Build TreeNode tree. Count total_folders, total_files. If entries exceed limit, set truncated=True and stop.

    4. **kb_grep(db, user_id, pattern, path=None, case_insensitive=False, max_matches=50) -> GrepResult**: Compile regex with re.compile (re.IGNORECASE if case_insensitive). On re.error, return GrepResult with error. Query document_content rows for user (optionally scoped to path subtree using folder path LIKE). For each doc, split content by newlines, search line-by-line, collect up to 5 line matches per doc. Stop at max_matches docs. Set truncated flag.

    5. **kb_glob(db, user_id, pattern) -> GlobResult**: Query all documents for user with their folder paths (LEFT JOIN folders). Build virtual path for each doc (folder.path + "/" + filename, or just filename for unfiled). Apply fnmatch.fnmatch() against pattern. Also try matching against just filename for patterns without "/".

    6. **kb_read(db, user_id, path, offset=None, limit=None) -> ReadResult**: Resolve document path. Query document_content. If offset/limit provided, split by newlines, slice, prepend 1-indexed line numbers (like `cat -n`). Return content, line_count, char_count, total_lines.

    Every tool function decorated with `@observe(name="kb_tool_{name}")` from `langfuse`. Every SQL query includes `WHERE user_id = ?`. Use `from langfuse import observe` (per Phase 1 decision).
