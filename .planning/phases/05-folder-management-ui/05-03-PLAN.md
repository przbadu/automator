1. **Install @dnd-kit/react** (run from `frontend/` directory):

2. **Update `DocumentsLayout.tsx`:**
   - Import `DragDropProvider` from `@dnd-kit/react`
   - Wrap the entire two-panel layout (folder tree sidebar + document list area) in `<DragDropProvider onDragEnd={handleDragEnd}>`
   - Implement `handleDragEnd(event)`:
     ```typescript
     const { source, target } = event.operation
     if (!source || !target) return
     const sourceData = source.data as { type: string; id: string }
     const targetData = target.data as { type: string; folderId: string }
     if (targetData.type !== 'folder') return
     if (sourceData.type === 'document') {
       await moveDocument(sourceData.id, targetData.folderId)
       await loadTree()
     } else if (sourceData.type === 'folder') {
       if (sourceData.id === targetData.folderId) return // prevent drop on self
       await moveFolder(sourceData.id, targetData.folderId)
     }
     await loadDocuments()
     ```
   - Show error toast (using existing toast/sonner if available, or console.error) if the backend returns an error (e.g., circular folder move)

3. **Update `FolderTreeItem.tsx`:**
   - Import `useDroppable` and `useDraggable` from `@dnd-kit/react`
   - Call `useDroppable({ id: \`drop-folder-${node.id}\`, data: { type: 'folder', folderId: node.id } })` to get `{ ref: dropRef, isDropTarget }`
   - Call `useDraggable({ id: \`drag-folder-${node.id}\`, data: { type: 'folder', id: node.id } })` to get `{ ref: dragRef }`
   - Combine refs: attach both to the folder button element (use a callback ref or a wrapper div with one ref on outer, one on inner)
   - Add visual drop indicator: when `isDropTarget` is true, add a highlight class (e.g., `ring-2 ring-primary bg-accent/50`) to the folder button
   - Configure drag activation with a distance constraint to prevent short clicks from triggering drags -- use the `activationConstraint` option in useDraggable: `{ distance: 8 }` (8px minimum movement before drag starts)

4. **Update `DocumentList.tsx`:**
   - Import `useDraggable` from `@dnd-kit/react`
   - For each document row, call `useDraggable({ id: \`drag-doc-${doc.id}\`, data: { type: 'document', id: doc.id } })` to get `{ ref: dragRef }`
   - Attach `dragRef` to the document row element
   - Add a drag handle visual indicator (e.g., GripVertical icon from lucide-react on the left side of each row) to hint that rows are draggable
   - Apply `cursor-grab` class to the row, `cursor-grabbing` while dragging if supported

5. **Update `DocumentUpload.tsx`:**
   - Make the upload drop zone also a `useDroppable` target with id `drop-upload-zone` and data `{ type: 'folder', folderId: selectedFolderId }` so desktop file drops onto the upload zone respect the selected folder
   - This ensures the existing HTML5 file drop and the @dnd-kit drop system don't conflict -- the HTML5 drop handler already handles file uploads, @dnd-kit handles document/folder moves

**Important notes from research:**
- @dnd-kit/react is v0.3.x (pre-1.0). If the API has issues, the context menus from Plan 02 already provide full move functionality as a fallback.
- The backend validates circular folder moves and returns 400 -- handle this by catching the error and showing a message.
- Configure distance activation constraint (8px) on draggables to prevent click-vs-drag conflicts (Research Pitfall 3).
