# Phase 4 Plan 02: Explorer Sub-Agent and Chat Integration

## Objective

Wire the KB exploration tools into an explorer sub-agent mode that chains multiple tools autonomously, implements the analyze_document delegation, and integrates with the chat router so KB exploration queries flow through the explorer automatically.

## Context

- @backend/app/services/sub_agent_service.py - Existing tool-calling loops (OpenAI + Anthropic)
- @backend/app/services/kb_agent_tools.py - KB tool definitions and executors from Plan 01
- @backend/app/services/sub_agent_tools.py - Tool dispatch with KB tool cases
- @backend/app/routers/chat.py - Chat SSE router with sub-agent integration
- @backend/app/services/intent_service.py - Intent classification with needs_explorer flag
- @backend/app/config.py - explorer_max_iterations setting

## Tasks

### Task 1: Add explorer mode to sub_agent_service.py
type="auto"

**Do:**
- Add EXPLORER_SYSTEM_PROMPT with strategy guidance for KB tool chaining
- Modify `run_sub_agent` to accept `mode` parameter (default None)
- When mode="explorer": use explorer system prompt, include KB tools, use explorer_max_iterations
- Pass mode through to both OpenAI and Anthropic loops for max_iterations override

**Done when:**
- `run_sub_agent(mode="explorer")` uses explorer prompt, KB tools, and explorer_max_iterations
- Existing document_analysis and tools modes unaffected

### Task 2: Implement analyze_document executor and wire chat router
type="auto"

**Do:**
- Implement `execute_analyze_document` in kb_agent_tools.py that delegates to `run_sub_agent` for document analysis
- Update `execute_tool` in sub_agent_tools.py to call the real analyze_document executor
- Update chat.py to route `needs_explorer` intent through explorer mode

**Done when:**
- analyze_document tool calls the document analysis sub-agent and returns collected text
- Chat router passes mode="explorer" when intent.needs_explorer is True
- Explorer sub-agent receives all KB tools including analyze_document

## Verification

- Backend starts without import errors
- Explorer mode uses correct system prompt and KB tools
- analyze_document executor delegates to document analysis sub-agent

## Success Criteria

- Explorer sub-agent can chain KB tools (tree, grep, read, etc.)
- analyze_document delegates to existing document analysis sub-agent
- Chat router routes KB exploration queries to explorer mode
