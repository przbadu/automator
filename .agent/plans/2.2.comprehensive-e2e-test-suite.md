# Comprehensive E2E Test Suite

## Complexity: ⚠️ Medium

## Context

The app has 3 ad-hoc test files organized by development module with duplicated helpers and inline login logic. We need a **structured regression test suite** that an agent can run after any code change to verify nothing is broken. The suite should cover all built features (Modules 1, 2, 2.1, and UI improvements) with clear acceptance criteria.

## Approach

Replace the existing 3 test files with a clean, organized suite split into **3 tiers**:
- **`api/`** — Fast API-level tests (no browser, no LLM needed)
- **`ui/`** — Browser-level UI tests (no LLM needed)
- **`llm/`** — Tests requiring a live LLM (slow, external dependency)

Shared utilities extracted into `fixtures/` to eliminate duplication.

## File Structure

```
tests/e2e/
  fixtures/
    test-data.ts          # Constants (URLs, credentials), sample data factories
    auth.ts               # apiLogin(request), uiLogin(page) helpers
    api-client.ts         # Typed API wrapper with auth headers
    sse.ts                # SSE response parser utility
    cleanup.ts            # Teardown helpers (delete all threads/docs/configs)

  api/                    # API tests — fast, no browser, no LLM
    health.spec.ts
    auth.spec.ts
    threads.spec.ts
    messages.spec.ts
    documents.spec.ts
    llm-configs.spec.ts

  ui/                     # Browser tests — no LLM needed
    auth.spec.ts
    chat.spec.ts
    settings.spec.ts

  llm/                    # Requires live LLM — slow
    chat-streaming.spec.ts
    auto-title.spec.ts
    rag-retrieval.spec.ts
```

**Delete after**: `module1.spec.ts`, `module2.spec.ts`, `ui-improvements.spec.ts`

## Playwright Config Update

Update `playwright.config.ts` with 3 projects for selective execution:

```ts
projects: [
  { name: 'api', testMatch: 'api/**/*.spec.ts', timeout: 60_000 },
  { name: 'ui',  testMatch: 'ui/**/*.spec.ts',  timeout: 60_000 },
  { name: 'llm', testMatch: 'llm/**/*.spec.ts', timeout: 120_000 },
]
```

Run commands:
- `npx playwright test` — all tests
- `npx playwright test --project=api` — fast API tests only
- `npx playwright test --project=api --project=ui` — everything except LLM
- `npx playwright test --project=llm` — LLM tests only

## Shared Fixtures

### `fixtures/test-data.ts`
- `BACKEND_URL`, `FRONTEND_URL`, `TEST_EMAIL`, `TEST_PASSWORD` constants
- `sampleDocument(content?)` — returns `{ name, mimeType, buffer }` for upload tests
- `uniqueEmail()` — `test-{uuid}@example.com` for signup isolation

### `fixtures/auth.ts`
- `apiLogin(request)` → `Promise<string>` — POST `/auth/login`, returns access_token
- `uiLogin(page)` → `Promise<void>` — fills login form, waits for chat UI

### `fixtures/api-client.ts`
Typed wrapper class holding `request` + `accessToken`, providing:
- `auth.login()`, `auth.signup(email, password)`, `auth.refresh(token)`, `auth.me()`
- `threads.create(title?)`, `threads.list()`, `threads.get(id)`, `threads.delete(id)`
- `threads.listMessages(id)`, `threads.sendMessage(id, content)` (raw response for SSE)
- `threads.stop(id)`
- `documents.upload(name, content)`, `documents.list()`, `documents.get(id)`, `documents.delete(id)`
- `llmConfigs.list()`, `llmConfigs.create(data)`, `llmConfigs.update(id, data)`, `llmConfigs.delete(id)`, `llmConfigs.getDefault()`

### `fixtures/sse.ts`
- `parseSSEResponse(body: string)` → `{ deltas: string[], doneEvent: object, fullContent: string }`

### `fixtures/cleanup.ts`
- `deleteAllThreads(client)`, `deleteAllDocuments(client)`, `deleteAllLLMConfigs(client)`

## Test Data Strategy

- **Self-contained**: Each test creates its own data and cleans up via `afterEach`/`afterAll`
- **No exact counts**: Assert "list contains my item" not "list has exactly N items" (shared test user)
- **Test user assumed to exist**: `test@example.com` created during initial setup, not by tests
- **Signup test uses unique email**: Avoids conflicting with other tests

## Implementation Order

1. Create `fixtures/` (test-data, auth, api-client, sse, cleanup)
2. Create `api/` tests (health → auth → threads → messages → documents → llm-configs)
3. Create `ui/` tests (auth → chat → settings)
4. Create `llm/` tests (streaming → auto-title → rag)
5. Update `playwright.config.ts` with 3 projects
6. Add `"test"` script to `package.json`: `"test": "npx playwright test"`
7. Delete old test files
