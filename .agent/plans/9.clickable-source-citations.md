# Plan: Clickable Source Citations with Chunk Viewer

## Context

Source citations currently show filename, chunk index, relevance score, and a 200-char preview. The user wants to click a source to see the **full chunk content** from the original document. This requires threading `document_id` through the retrieval pipeline and adding a chunk-fetching API endpoint + a frontend dialog.

**Complexity:** ⚠️ Medium — touches multiple backend services and adds a new UI component, but each change is straightforward.
