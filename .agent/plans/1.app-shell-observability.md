# Module 1: App Shell + Observability (Updated)

## Context
First module of the Agentic RAG Masterclass. No application code exists yet. Three key changes from original PRD:
1. **SQLite3** replaces Supabase (simpler, no external deps)
2. **JWT auth** replaces Supabase Auth (bcrypt + PyJWT)
3. **Chat Completions API** replaces Responses API (OpenAI-compatible, works with local LLMs)

We manage chat history ourselves from day one (no `previous_response_id`). This effectively merges the Module 1→2 transition.

**Complexity:** ⚠️ Medium — 7 tasks across frontend, backend, and database.

## Database Schema (SQLite3)

```sql
PRAGMA journal_mode=WAL;

CREATE TABLE IF NOT EXISTS users (
    id TEXT PRIMARY KEY,
    email TEXT UNIQUE NOT NULL,
    password_hash TEXT NOT NULL,
    created_at TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at TEXT NOT NULL DEFAULT (datetime('now'))
);

CREATE TABLE IF NOT EXISTS threads (
    id TEXT PRIMARY KEY,
    user_id TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    title TEXT NOT NULL DEFAULT 'New Chat',
    created_at TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at TEXT NOT NULL DEFAULT (datetime('now'))
);
CREATE INDEX IF NOT EXISTS idx_threads_user_id ON threads(user_id);

CREATE TABLE IF NOT EXISTS messages (
    id TEXT PRIMARY KEY,
    thread_id TEXT NOT NULL REFERENCES threads(id) ON DELETE CASCADE,
    user_id TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    role TEXT NOT NULL CHECK (role IN ('user', 'assistant')),
    content TEXT NOT NULL,
    metadata TEXT NOT NULL DEFAULT '{}',
    created_at TEXT NOT NULL DEFAULT (datetime('now'))
);
CREATE INDEX IF NOT EXISTS idx_messages_thread_id ON messages(thread_id);
CREATE INDEX IF NOT EXISTS idx_messages_user_id ON messages(user_id);
```

No `openai_response_id` — we manage history ourselves. No RLS — every query includes `WHERE user_id = ?`.

- `AuthGuard.tsx` — redirect to login if unauthenticated
- `LoginForm.tsx` / `SignUpForm.tsx` — email/password forms

### Task 6: Chat Completions API + SSE Streaming
Stateless completions — we load and send full message history with each request.

**Files:** `services/llm_service.py`, `routers/chat.py`, `models/chat.py`

**Endpoints:**
- `POST /threads` — create thread
- `GET /threads` — list user's threads (WHERE user_id = ?)
- `GET /threads/{id}` — get thread (WHERE id = ? AND user_id = ?)
- `DELETE /threads/{id}` — delete thread + cascade
- `GET /threads/{id}/messages` — list messages
- `POST /threads/{id}/messages` — send message, stream response via SSE

**LLM service core (`llm_service.py`):**
1. Load all messages for the thread from DB
2. Build `messages` array: `[{"role": m.role, "content": m.content} for m in history]`
3. Call `openai_client.chat.completions.create(stream=True, model=settings.llm_model, messages=messages)`
4. Iterate streaming chunks, yield deltas

**SSE format:**
- `data: {"type": "delta", "content": "..."}` — streaming tokens
- `data: {"type": "done", "message_id": "..."}` — completion

**After streaming:** Save both user + assistant messages to DB, update thread's `updated_at`.

**Validate:** Send message → SSE stream → follow-up has context → messages in DB → delete cascades.
